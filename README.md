# homey-utelys
## Smart utelys for Homey

Slår utelyset på i skumringen og av i grålysningen, basert på solens høyde for Homeys posisjon (tar automatisk hensyn til årstid, midnattssol og mørketid). Valgfri lyssensor og nattpause. Konfigureres under appens innstillinger.

```
npm install
npx homey app install
```
