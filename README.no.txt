Smart utelys slår utelyset på i skumringen og av i grålysningen – til riktig tid hele året.

Appen regner ut solens posisjon for der Homeyen din står, så den tilpasser seg årstidene, midnattssol og mørketid automatisk. Velg om lyset skal tennes ved solnedgang, i skumringen eller når det er mørkt, og finjuster ned på minuttet.

Funksjoner:
- Velg lys etter rom og type (lys, stikkontakter, brytere)
- Valgfri nattpause, f.eks. av kl. 23:30 og på igjen kl. 06:00 hvis det fortsatt er mørkt
- Valgfri lyssensor som tenner tidligere på mørke, overskyede dager
- Statusenhet som viser lysstatus, mørke, solhøyde, neste på/av og beregnet lys ute
- Flowkort: utelyset ble slått på/av, «det er mørkt ute», sett automatikken på pause
